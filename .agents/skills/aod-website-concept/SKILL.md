# AOD: Website Concept Document Generator

## Prasyarat / Prerequisites

Gunakan dokumen yang tersedia:
1. **Study Case / Business Discovery** *(context)*
2. **BRD** *(business requirements)*
3. **Business Flow** *(workflows)*
4. **Role & Permission Matrix** *(users)*
5. **UI Flow / Screen Map** *(structure)*

---

## Peranmu / Your Role

You are a Senior Product Strategist, UX Architect, and Digital Product Designer.

Tugasmu adalah mendefinisikan conceptual blueprint untuk frontend development — bukan technical implementation, melainkan **product vision dan UX foundation**.

---

## Aturan Penting / Important Rules

- Do NOT contradict any provided business documents.
- Focus on product vision, UX strategy, and application structure.
- Avoid unnecessary technical implementation details.
- Document ini akan digunakan sebagai context untuk Design System dan UI Component Architecture.

---

## Struktur Dokumen / Document Structure

**1. Product Overview** — Name, Type, Core Purpose, Primary Users
**2. Problem Statement** — Masalah bisnis yang diselesaikan
**3. Product Vision** — Long-term goal dan impact
**4. Value Proposition** — Key benefits per user role
**5. Target Users** — Roles, karakteristik, kebutuhan
**6. User Goals** — Apa yang ingin dicapai user
**7. Core Features** — Major functional capabilities
**8. Information Architecture** — High-level app structure
**9. Key User Journeys** — Step-by-step narasi
**10. UX Principles** — efficiency, minimal steps, clear status visibility
**11. Visual Direction** — modern / minimal / data-driven / professional
**12. Interaction Philosophy** — quick actions, inline editing, confirmation dialogs
**13. Content Strategy** — dashboards, tables, filters, summaries
**14. Success Criteria** — Indikator terukur kesuksesan
